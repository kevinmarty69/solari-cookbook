Designed to Fail Closed

Read-only by product design.

DoneLedger checks external agent work. It does not create, validate, pay or delete customer invoices.

Read the Threat Model ↗
Credentials
Sent only to the server for the active run and never written to the report store.
Permission Gates
A live verdict requires negative create and payment probes plus cleanup evidence.
Sharing
Reports are private by default, expire after 7 days and use revocable fragment tokens.
Scope
One ERP, one manifest, one read-only verifier. No approval or payment automation.

FAQ

Clear boundaries before access.

Does DoneLedger change my Dolibarr data?

No. The SaaS path accepts one read-only account and fails unless create and payment actions are denied.

What is stored?

The condensed verdict, fingerprints, lifecycle evidence and timestamps. ERP credentials are not persisted.

Is this an accounting approval?

No. A verified draft is not approved, posted, payable or paid. DoneLedger verifies a narrow completion claim.

Why Solari?

Solari provides isolated remote browser sessions and sandbox execution for a reproducible verifier boundary.
